# 🍄 Super Mario Run

A lightweight, browser-based Super Mario-inspired endless runner built with **HTML, CSS, and vanilla JavaScript**. Jump over obstacles, collect coins, beat the timer, and save the princess!

## ✨ Features

- 🎮 Endless side-scrolling run with auto-running character
- ⏱️ Race against the countdown timer — reach the end before time runs out
- 🪙 Collect spinning golden coins to boost your score
- 🧱 Dodge colorful blocks and keep your lives
- 💚 3 lives system with damage blink effect
- 🏁 Win / Game Over screens with final score
- 📋 Modern glassmorphism **How to Play** popup
  - Desktop: Press `SPACE`
  - Mobile: Tap the screen
- 🔊 Sound effects and game audio
- 👤 Developer profile section
- 📱 Fully responsive for desktop and mobile

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Tailwind CSS v4
- Vanilla JavaScript
- Press Start 2P font (retro pixel style)
